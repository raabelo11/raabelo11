### 👨‍💻 About Me

I'm a **Software Engineer** focused on backend development, distributed systems and cloud technologies.

My main expertise is within the **.NET ecosystem**, working with **C#, ASP.NET Core, microservices, APIs and messaging systems**. I also have experience with Java/Spring Boot and contribute to front-end applications when needed.

I enjoy working on systems where **reliability, scalability, performance and clean architecture** matter.

Currently, my main areas of interest are:

* Backend development with **.NET / C#**
* **Microservices & Distributed Systems**
* Asynchronous communication and **Message Brokers**
* **Kafka, RabbitMQ & IBM MQ**
* **Azure & Cloud Infrastructure**
* Clean Architecture, SOLID & software design
* Observability, CI/CD & containers
* SQL and NoSQL databases
